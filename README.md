## ✨ Overview

Liquid Glass Music Player is an iOS project built with SwiftUI, exploring a modern music-player interface inspired by Apple's Liquid Glass design language.

The project focuses on immersive visuals, music screens, and a clean native iOS experience.

## 🌟 Highlights

- 🎨 Liquid Glass-inspired visual design
- 🎵 Dedicated music-player screens
- 🖼️ Visual artwork and animated assets
- 📱 Native SwiftUI interface
- 🧩 Organized and modular view structure

## 🚀 Getting Started

### Requirements

- macOS
- Xcode
- An iOS Simulator or compatible iPhone

### Installation

**1. Clone the repository**

    git clone https://github.com/Mannagurung121/LiquidGlassMusicPlayer.git

**2. Open the project**

Open `WWDC26-Mini-Projects.xcodeproj` in Xcode.

**3. Run the app**

Choose an iOS Simulator or connected iPhone and press `⌘ + R`.
